# Social Feed UI

Interactive social feed built with vanilla HTML/CSS/JavaScript.

## Features

- Create posts with tags
- Search by author/content/tags
- Tag filter chips
- Like / unlike with counts
- Inline comments
- `localStorage` persistence
- Schema + source tests

## Quick start

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Tests

```bash
python3 -m unittest discover -s tests -p "test_*.py"
```
